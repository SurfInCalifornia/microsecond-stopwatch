## About this software

This is a Windows-only, fully offline digital stopwatch. This software does not auto-update. The smallest unit on this stopwatch is 1 microsecond. The largest unit is hours, however after 24 hours the stopwatch will keep counting. For example, exactly one day and one hour after the stopwatch is started, the stopwatch will read 25:00:00.000000. For your information the attached MSI installer was made with Advanced Installer. The `.aip` files used to build the installer are not publicly available for privacy reasons.
